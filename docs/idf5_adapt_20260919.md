# IDF5 / Arduino 3 适配说明

> 状态：**已合入 `main`（PR #9，2026-09-19）** · 首迁固件 **v1.1.28**；当前 tip **v1.1.39**  
> 平台：pioarduino **55.03.311** = Arduino-ESP32 **3.3.11** / ESP-IDF **5.5.5**  
> 迁移前基线：v1.1.20（Arduino 2 / IDF 4.4）  
> 总览：[CURRENT.md](CURRENT.md)

## 为何换平台

库存 PlatformIO `espressif32` 6.x/7.x 仍绑 Arduino 2.x / IDF 4.4。S3 上 legacy RMT RX 数据通路只会推送空环形缓冲项（见 [s3_deep_dive_roadmap.md](s3_deep_dive_roadmap.md) §1），必须迁到 IDF5 新 `driver/rmt_rx.h` 才能重开 PPS 硬件捕获。

## `platformio.ini`

```ini
platform = https://github.com/pioarduino/platform-espressif32/releases/download/55.03.311/platform-espressif32.zip
```

C3 / S3 共用 `[idf5]`；板级差异在 `include/config.h`。

## 代码改动摘要

| 区域 | 变化 |
|---|---|
| 温度 | C3/S3 均走 `temperatureRead()` |
| RMT | IDF5 `rmt_new_rx_channel` + `rmt_receive` + `on_recv_done`；**默认 `GPS_PPS_RMT_EN=0`** |
| RGB | `rgbLedWrite`（Arduino 3） |
| NMEA | **GGA+RMC+ZDA** + PCAS persist-skip（无 RMC 无法锁定，见 [gps_lock_nmea_fix_20260919.md](gps_lock_nmea_fix_20260919.md)） |
| 功耗（S3） | 160 MHz + WiFi MIN_MODEM（见 [power_save.md](power_save.md)） |
| C3 分区 | `partitions/default_ota_1750k.csv`（~1.75 MB OTA 槽） |

## 模块兼容性

除温度 / RMT / RGB 外，WiFi、NTP、Web、OTA、Settings、OLED、编码器、LocalClock 等 API 在 Arduino 3.3.11 下仍有效（迁移时全量审核通过）。

**体积**：`lib_deps` + LDF 按需；`lib_ignore = ble/Matter/…` 缩小编译面。勿对共享框架做激进 `custom_component_remove`（易弄坏 `Update`）。

## 编译

```text
pio run -e esp32-c3
pio run -e esp32-s3
# 可选：临时 -DGPS_PPS_RMT_EN=1
```
