- 形态：LCK→ACQ 4s→LCK；`ppsCount` **全程连续递增**（边沿未丢），`ppsBadStreak` 判定间隔异常（疑似毛刺/双边沿）→ 诚实降级 ACQ（q=0xFFFFFFFF），residual ±1000 ms 为 NMEA 交叉检核主动告警，数秒自愈。
